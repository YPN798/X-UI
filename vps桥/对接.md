# 桥控制台对接文档

版本以 `GET /api/health` 的 `版本` 为准。当前实现对应 `2026-09-11.7`。

监听：

| 服务 | 默认 | 说明 |
|---|---|---|
| SOCKS5 | `127.0.0.1:41000` | 给本机 Xray 用，不要对公网 |
| 管理页 / API | `0.0.0.0:41001` | 网页和控制接口同一端口 |

网页：`http://<主机>:41001/`  
本文：`http://<主机>:41001/docs`  
机器目录：`GET /api`  
机器本文：`GET /api/docs`

---

## 1. 鉴权

除 `GET /`、`GET /docs`、`GET /login`、`GET /api/panel`、`POST /api/login`、`POST /api/logout`、`OPTIONS /api/*` 外，其余接口都要鉴权。

机器用下面两种之一，**不要把密码写进 URL**：

```
X-Pass: <web_pass>
Authorization: Bearer <web_pass>
```

也认 `Authorization: Basic`（取冒号后面那一段当密码）。网页登录后带 Cookie `xui_bridge`。

默认密码见配置 `web_pass`，出厂是 `YPN940815...`（三个点算密码）。

统一信封：

| 字段 | 类型 | 说明 |
|---|---|---|
| `ok` | bool | 成功 true；失败 false |
| `err` | string | 失败原因。401 未登录，403 密码不对，400 参数不对，404 没有这个接口 |

跨域：接口带 CORS。预检 `OPTIONS` 回 204。

## 2. 建议调用顺序

```
GET  /api/health          探活
GET  /api/status          读全量（或拆开 /api/config /api/pool /api/stats）
POST /api/set             改地区、条数、换新间隔等
POST /api/regions/add     需要时改随机国库
POST /api/rotate          按当前设置换一批 IP
GET  /api/pool            核对出口和健康数
GET  /api/stats           看今日消耗
```

换地区并立刻提新 IP：

```bash
PASS='你的web_pass'
HOST='http://127.0.0.1:41001'
H=(-H "X-Pass: $PASS" -H "Content-Type: application/json")

curl -sS "${H[@]}" -d '{"sc_cntry":"JP"}' "$HOST/api/set"
curl -sS "${H[@]}" -X POST "$HOST/api/rotate"
curl -sS "${H[@]}" "$HOST/api/pool"
```

国家留空则每批从随机国库抽一个：

```bash
curl -sS "${H[@]}" -d '{"sc_cntry":"","sc_state":"","sc_city":""}' "$HOST/api/set"
curl -sS "${H[@]}" -X POST "$HOST/api/rotate"
```

## 4. 读接口字段

### GET /api/health

不含密钥。适合监控。

| 字段 | 类型 | 说明 |
|---|---|---|
| `版本` | string | 桥代码版本 |
| `listen` | string | SOCKS 监听，如 `127.0.0.1:41000` |
| `web` | string | 管理页监听，如 `0.0.0.0:41001` |
| `健康` | int | 健康代理条数 |
| `总数` | int | 池内总条数 |
| `供应商` | string | `闪臣` / `IPIPGO` / `无` |
| `这批地区` | string | 本批提取地区，如 `JP` 或 `随机` |
| `上次补` | string | 最近一次补池/换新说明 |
| `上次换新` | string | 上次换新时间 `YYYY-MM-DD HH:MM:SS` |

### GET /api/status

`/api/health` 的字段都有，另外还有下面全部。`proxies` 与 `池` 是同一份，兼容旧调用。

#### 监听与分发

| 字段 | 类型 | 说明 |
|---|---|---|
| `listen` | string | SOCKS `主机:端口` |
| `web` | string | 管理 `主机:端口` |
| `panel_url` | string | 同机 X-UI 面板地址，问不到则为空 |
| `mode` | string | `round_robin` 轮询 / `least_conn` 谁连接少走谁 |
| `sticky` | string | 空或 `关`=不粘；`host`=按目标主机粘住 |
| `pool_size` | int | 池目标条数 |
| `fail_n` | int | 失败几次摘除 |
| `check_interval` | int | 验活间隔秒 |
| `check_conc` | int | 同时验活条数 |
| `check_host` | string | 验活主机，默认 `www.dola.com` |
| `check_port` | int | 验活端口，默认 443 |
| `connect_timeout` | int | 连上游超时秒 |
| `fetch_url` | string | 别家提取接口 |
| `fetch_cmd` | string | 命令提取，stdout 一行一条 |
| `fetch_scheme` | string | 空=按返回；`socks5` / `http` 强制 |

#### 提取源

| 字段 | 类型 | 说明 |
|---|---|---|
| `供应商` | string | 当前真正在用的源 |
| `供应商选` | string | `auto` / `shanchen` / `ipipgo` |
| `sc_base` | string | 闪臣接口根 |
| `sc_key` | string | 闪臣 Key（明文，机器对接用） |
| `sc_count` | int | 每次提几条，1–500 |
| `sc_time` | int | `0`=5-30 分钟；`2`=1-6 小时；`1`=每请求一换 |
| `sc_protocol` | string | `s5` / `http` |
| `sc_cntry` | string | 钉死的国家码，空=随机 |
| `sc_state` | string | 州/省，空=整国 |
| `sc_city` | string | 城市，空=整国 |
| `sc_white` | int | `1` 撞白名单自动加 |
| `go_key` | string | IPIPGO key |
| `go_url` | string | IPIPGO 提取链接 |
| `go_user` | string | IPIPGO 账号 |

#### 换新 / 更新

| 字段 | 类型 | 说明 |
|---|---|---|
| `auto_rotate` | int | 自动换新秒，0=关 |
| `换说` | string | 人读的换新策略 |
| `下次换` | int | 还有多少秒换；未开为 `-1` |
| `上次换新` | string | 时间 |
| `上次补` | string | 最近补/换说明 |
| `上轮验活` | string | 上一轮验活摘要 |
| `上次源` | string | 上次提取成功的源 |
| `这批地区` | string | 本批地区 |
| `随机国库` | string[] | 随机抽取用的国家码 |
| `auto_update` | int | `1` 开自动更新 |
| `update_minutes` | int | 多少分钟查一次代码 |
| `更新说` | string | 上次自动更新结果 |

#### 流量

| 字段 | 类型 | 说明 |
|---|---|---|
| `健康` | int | 健康条数 |
| `总数` | int | 池总条数 |
| `上行` / `下行` | int | 当前池内各条之和（字节） |
| `上行文` / `下行文` | string | 人读 |
| `总上行文` / `总下行文` | string | 累计人读（换新重启不清） |

| `今日` | string | `YYYY-MM-DD`（服务器本地时区，安装脚本会设东八区） |
| `今日上行` / `今日下行` / `今日合计` | int | 今日字节 |

|---|---|---|
| `健康` | int | |

## 5. 写接口

请求体 JSON。`/api/set` **只改传入的字段**，没传的不动。`web_pass` 不会走 `/api/set`，改密码用 `/api/passwd`。

### POST /api/set

可写字符串：

`mode` `sticky` `fetch_url` `fetch_cmd` `fetch_scheme` `sc_base` `sc_key` `sc_protocol` `sc_cntry` `sc_state` `sc_city` `provider` `go_base` `go_key` `go_url` `go_user` `go_host`

可写整数：

`pool_size` `fail_n` `check_interval` `check_conc` `connect_timeout` `auto_rotate` `sc_count` `sc_time` `sc_white` `go_port` `auto_update` `update_minutes`

只写不回显：

`sc_code` `go_pass`（空=不改）

还可传 `随机国库`（数组或逗号分隔字符串）整表替换。

返回：最新 `/api/config`，外加 `msg`。

```json
{"sc_cntry":"JP","pool_size":30,"auto_rotate":300}
```

### POST /api/regions

```json
{"地区":["JP","KR","SG"]}
```

也认 `码` / `code` / `国` / `codes` / `随机国库`。国家码必须是两位字母。返回同 GET `/api/regions`，带 `msg`。

### POST /api/regions/add

```json
{"码":"TW"}
```

可一次多个。已在库里的会跳过。`新加` 是真正新写入的。

### POST /api/regions/del

```json
{"码":"TW"}
```

至少留一个国家，否则 400：`至少留一个国家，随机提取才抽得到`。

### POST /api/fill

无 body。按 `pool_size` 补到目标。返回 `{msg, health}`。

### POST /api/rotate

无 body。丢掉来源为「拉取」的代理，按当前地区重新提。手加的不动。返回 `{msg, health}`。

### POST /api/add

```json
{"串":"socks5://user:pass@1.2.3.4:1080\nsocks5://..."}
```

或

```json
{"proxies":["socks5://user:pass@1.2.3.4:1080"]}
```

也认 `IP|端口|用户|密码`。返回 `{n, err, pool}`。`n` 是成功条数，`err` 是失败说明（可能为空）。

### POST /api/del

```json
{"id":"a1b2c3d4"}
```

也认 `号`。返回 `{ok, id, pool}`。`ok=false` 表示没找到这条。

### POST /api/clear

无 body。返回 `{n}` 删除条数。

### POST /api/sc/setup

```json
{
  "provider": "auto",
  "key": "闪臣key",
  "code": "安全码",
  "go_key": "",
  "go_user": "",
  "go_pass": ""
}
```

`key` 也认 `sc_key`，`code` 也认 `sc_code`。会存凭证、尽量加白名单、立刻换新。返回 `{步:[], msg, config}`。

### POST /api/sc/white

```json
{"ip":"","备注":"xui-bridge"}
```

`ip` 空=本机出口。`备注` 也认 `remark`。返回 `{好, msg}`。

### POST /api/sc/unwhite

```json
{"id":"","ip":""}
```

`id` 或 `ip` 有一个就行。返回 `{好, msg}`。

### POST /api/sc/refresh

无 body。返回 `{闪臣: {...}}`。

### POST /api/update

无 body。去仓库对版本，变了就覆盖 `/opt/xui-bridge` 并重启。返回 `{msg}`。配置和池不碰。

### POST /api/traffic/reset

无 body。累计和各条计数清零，**日表保留**。返回 `{msg}`。

### POST /api/passwd

```json
{"web_pass":"新密码"}
```

也认 `新`。至少 4 位。返回 `{msg}`，并换 Cookie。之后请求用新密码。

### POST /api/login

```json
{"pass":"web_pass"}
```

成功种 Cookie。网页用。

## 6. 错误码（闪臣）

出现在 `上次补`、`余额说`、`白名单说` 里。

| 码 | 含义 |
|---|---|
| 1001 | 鉴权失败，检查 API Key |
| 1002 | 参数错误或校验失败 |
| 1003 | 账号不可用 |
| 1004 | 本机公网 IP 不在动态白名单 |
| 1005 | 没有可用动态流量或流量用完 |
| 1006 | 安全码不对 |
| 1007 | 白名单条数超上限 |
| 2001 | 闪臣系统处理失败 |

## 7. 语言示例

### Python

```python
import json, urllib.request

HOST = "http://127.0.0.1:41001"
PASS = "YPN940815..."

def 桥(路, 身=None):
    头 = {"X-Pass": PASS}
    data = None
    if 身 is not None:
        头["Content-Type"] = "application/json"
        data = json.dumps(身).encode()
    req = urllib.request.Request(HOST + 路, data=data, headers=头,
                                 method="GET" if 身 is None else "POST")
    with urllib.request.urlopen(req, timeout=30) as r:
        return json.loads(r.read().decode())

print(桥("/api/health"))
print(桥("/api/stats")["今日合计文"])
桥("/api/set", {"sc_cntry": "JP"})
print(桥("/api/rotate", {})["msg"])
```

### curl

```bash
H=(-sS -H "X-Pass: $PASS" -H "Content-Type: application/json")
curl "${H[@]}" "$HOST/api/health"
curl "${H[@]}" "$HOST/api/status"
curl "${H[@]}" "$HOST/api/stats"
curl "${H[@]}" -d '{"码":"TW"}' "$HOST/api/regions/add"
curl "${H[@]}" -d '{"码":"TW"}' "$HOST/api/regions/del"
curl "${H[@]}" -d '{"sc_cntry":"KR","sc_count":30}' "$HOST/api/set"
curl "${H[@]}" -X POST "$HOST/api/rotate"
curl "${H[@]}" -X POST "$HOST/api/fill"
```

## 8. 注意

- SOCKS 只应给本机 Xray。真正上网的是池里的住宅代理。
- `sc_cntry` 为空时从 `随机国库` 抽；钉死了就不随机。
- 随机库加减立刻落盘，下一轮补池/换新生效。正在用的这批不会因为删国家而立刻换掉，要自己 `rotate`。
- `/api/status` 里有 `sc_key`。日志、监控不要全文打印。
- 安全码、IPIPGO 密码只写不读。
- 日统计按服务器本地日历日，过零点换桶。最多 60 天。
- 自动更新只覆盖 `/opt/xui-bridge` 代码，不碰 `/etc/xui-bridge/config.json`。
